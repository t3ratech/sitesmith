# T3rnel Sitesmith site — sitesmith.t3ratech.co.zw

Public customer-facing website, trust verification hub, and AEO/SEO knowledge base for **T3rnel Sitesmith** by **Teratech Solutions (Private) Limited** (`https://sitesmith.t3ratech.co.zw/` and `https://t3ratech.co.zw/sitesmith`).

## Layout

Generated by `../scripts/build-site.mjs` from `../data/pricing.json` (never edit the HTML by hand):

- `index.html`: what Sitesmith is, how it works, the Visibility Launch, the two designs, prices.
- `pricing/`: the one price list, Stay Visible, payment methods.
- `how-it-works/`, `verify/` (how to check an email is really from us), `faq/` (FAQPage JSON-LD), `privacy/`, `404.html`.
- `llms.txt`, `sitemap.xml`, `ai/summary.json`, `ai/faq.json`.

Hand-written and kept: `AGENTS.md`, `skill.md`, `openapi.json`, `agents.json`, `robots.txt`, `.well-known/*`, `assets/`.

## Build & Verify

```bash
node products/t3rnel-sitesmith/scripts/build-site.mjs
node scripts/site_conformance.mjs products/t3rnel-sitesmith/site
```

## Publish

GitHub Pages from `github.com/t3ratech/sitesmith` (custom domain `sitesmith.t3ratech.co.zw`, DNS: CNAME `sitesmith` to `t3ratech.github.io` in the WebDev DNS manager):

```bash
rsync -a --checksum --delete --exclude=.git --exclude=README.md --exclude=DESIGN.md products/t3rnel-sitesmith/site/ /mnt/ext4_work/sitesmith-site/
cd /mnt/ext4_work/sitesmith-site && git add -A && git commit -m "site: <what changed>" && git push
```
